# 辨识与设计：公式、判据、脚本清单

## 1. 数据质量先看这五个数

每个频点（每段）都要算：

| 指标 | 判据 | 不达标说明 |
| --- | --- | --- |
| 位置通道拟合 R² | >0.85 | 噪声大或过程非平稳 |
| 每周期采样点数 `fs_loc/f` | ≥4（≥10 才谈谐波） | 采样率不够，重建出的输入已失真 |
| 3 次谐波 / 基波 | ≤12% | **粘滑**：激励幅值不够，该点不能用于线性辨识 |
| 正负摆幅不对称 `(p+−p−)/(p++p−)` | \|·\| < 10% | 摩擦/线缆存在方向偏置 |
| 窗口内净漂移 / 振荡速度 | <5% | 静摩擦蠕动（直流分量） |

拟合基函数固定用 `[cos, sin, 直流, 线性趋势]`：直流吸收窗口截断偏差，线性趋势吸收摩擦蠕动；少了趋势项会把蠕动算进基波相位。频率要在记录值 ±2% 内做一维搜索取残差最小（固件记录频率与真实任务频率可能差几个百分点）。

## 2. 灰箱最小二乘（对参数线性，不需要非线性迭代）

电机侧，输入 τ、输出 θ 或 ω，模型 `J·θ'' + b·θ' + k·θ = τ`：

```
位置通道 H_θ = 1/(J s² + b s + k)   → Z = 1/H_θ = (k − ω²J) + j(ωb)    对 (k,J,b) 线性
速度通道 H_ω = s/(J s² + b s + k)   → Z = 1/H_ω = b + j(ωJ − k/ω)      对 (b,J,k) 线性
```

把实部/虚部堆叠起来做普通最小二乘即可；延迟单独一维扫描（0~20 ms、步长 0.1 ms）：先把 `H_meas·e^{+jωTd}` 去掉延迟再估参数，取残差最小的 Td。**别把一阶模型拟合出的 9~14 ms 当真实延迟**（那是结构失配的产物）；CAN+电流环的真实延迟只有 1~2 ms。

**摩擦描述函数（这类关节的主导非线性）**：`J·ω' + (4/π)·τ_c·sign(ω) = τ`

```
G_ω(jω) = 1/( jωJ + c/|Ω| ),  c = (4/π)·τ_c,  |Ω| = 该频点的速度幅值
LTI 判别： Re(Z)·|Ω| 应为常数 = c； Im(Z)/ω 应为常数 = J
```

两个图形判据能一眼区分"线性粘性阻尼"与"库仑摩擦"：LTI 要求 `Re(1/G)` 与频率无关；实测若 `Re(1/G)` 随频率上翘、而 `Re(Z)·|Ω|` 是常数，那就是库仑摩擦。**三路交叉验证 τ_c**：描述函数拟合值、`b_eff` 对 `1/|Ω|` 的线性回归截距/斜率、以及低频粘滑波形上直接读出的起动阈值——三者应同量级（本工程 0.145 / 0.157 / 0.11~0.15 N·m）。

## 3. 按相位裕度闭式解增益

**内环（速度环，对象取最坏 b=0）**：`L = (Kp + Ki/s)/(J s)`

```
θ  = PM + ωc·Td(度)                      % 目标裕度 + 延迟相位
Ki = J·ωc²·cosθ      Kp = J·ωc·sinθ      % 由 |L(jωc)|=1 与 ∠L(jωc)=−180°+PM 解出
```

**外环（角度环）**：对象 = `0.5·T_speed_closed(s)/s`（0.5 来自减速比：关节角=电机角/ratio，而外环输出的是电机侧速度，这个系数必须算进去），且 `∠G = −90° − atan(ω/ω_ci)`（内环一阶滞后）：

```
θ   = (−30° + atan(ωc/ω_ci) + ωc·Td)·π/180      % 要求 ∠L = −120°（PM=60°）
|G| = 0.5/(ωc·√(1+(ωc/ω_ci)²))   Kp = cosθ/|G|   Ki = −sinθ/|G|·ωc
```

约束与经验：

- **内/外带宽比 ≥2.5**，否则 PI 会解出负 Ki（说明外环要求超前相位，PI 给不了）。
- **PM 目标**：内环 65°（二阶系统稳定时间在 ζ≈0.7 时最短）、外环 60°。
- **带宽上限不是力矩，而是机械纹波**：用 `|C·S|@f_ripple` 衡量"环路会不会去跟纹波较劲"，<0.8 比较安全（本工程内环取 3.5 Hz，`|CS|@10Hz≈0.75`，10 Hz 纹波引起的力矩活动仅约 0.06 N·m）。
- **外环 PM 会被"内环低速变慢"卡住**：摩擦阻尼大 → 内环带宽降 → 外环相位裕度降（本工程曾卡在 52°）。上摩擦前馈后摩擦被抵消，这个问题基本消失——**前馈与带宽是配套的**。
- **稳态外环带宽**（角度参考→关节角，−3dB）≈ 外环穿越频率的 1.0~1.2 倍，且随 b 变化，报带宽必须带工况（本工程 1.55~2.79 Hz）。

## 4. 验收判据

- 拟合点复频响相对误差 <15%（本工程模型 D 6.6~13.6%）；留一验证中位 <25%。
- 时域 NRMSE（同工况 1 ms 仿真 vs 实测）<50%，且**趋势一致**；量值差异要能解释（未建模静摩擦、传动柔性、机械纹波）。
- 实机阶跃：`saturated_ticks=0`、`fault=0`；上升时间与模型差落在采样量化误差内；**力矩不出现反复大幅跳变**（看相轨迹是否"一进一退"而不是反复绕圈）。
