# 关节辨识与 PID 整定（云台轴通用）

目标：先拿到一个**可解释的关节模型**（惯量 J、阻尼/摩擦、延迟），再用它**按裕度指标**（而不是试凑）算出速度环与角度环增益，最后用实机阶跃/扫频确认。这套方法在一台云台 yaw 轴上验证过：辨识复现误差 2~8%，实机上升时间与模型预测差 4%。

Pitch 轴实机案例（工作点选择、开环扫频、全行程标定、阶跃拟合、前馈和验证）见 [`../pitch-axis/README.md`](../pitch-axis/README.md)。

## 不可省略的原则

1. **先辨识，再整定。** 不要拿"看起来差不多"的旧模型调参。辨识必须**开环**（力矩直接给、绕过所有环路），否则测到的是环路而不是对象。
2. **这个轴通常不是 LTI。** 库仑摩擦让等效阻尼 ∝ 1/速度幅值：`b_eff = b_vis + (4/π)·τ_c/|Ω|`。同一套机械在不同振荡幅值下测出的"增益"能差 3~4 倍——历史上三个互相矛盾的模型（低频增益 10.8 / 3.7 / 2.9）就是这么来的。**报模型参数必须同时报 |Ω| 或激励幅值**，否则别人复现不了。
3. **激励幅值有上下限。** 下限是静摩擦起动阈值（低于它就粘滑：位置波形 3 次谐波 >20%、摆幅远小于线性预测）；上限是机械限位/线缆余量。**要提高信噪比就加"周期数"，不要加幅值**——加幅值只会把轴推进非线性区。
4. **裕度按最坏情况设计。** 用 `b=0`（纯惯量：快摆时摩擦阻尼消失）整定，才能保证任何工况都有裕度；只在带摩擦的模型上整定，实机会在快摆时啸叫。相位裕度 ≥60° 是合理起点。
5. **外环不需要 D。** 串级里内环速度环已提供阻尼；D 加在误差上会在参考阶跃瞬间产生力矩尖峰（实测比不用 D 大 6 倍）。角度环用 PI。
6. **摩擦前馈用平滑饱和，不要 sign()。** `τ_ff = τ_c·sat(ω_ref/ω_lin)`：粘性阻尼≈0 时方波前馈会在速度过零处灌一个 2τ_c 的阶跃，实测把 0.3~0.45 Hz 跟踪误差恶化 35~50%。前馈要用**参考**速度驱动，不要用实测速度（噪声会让符号抖）。
7. **验证必须落到实机。** 模型只能预测趋势（趋势几乎总对，量值差 20~100% 是常态）：把同一套 1 ms 非线性仿真（含离散 PID、积分限幅、输出限幅、前馈、`τ_c·tanh(ω/w_s)` 摩擦、齿轮比）与实测叠在同一张图上比。

## 流程

1. **采数据**：开环力矩逐频点驻留正弦；频点对数分布铺 1~1.5 个十倍频程（例 0.3→7 Hz、相邻比值≈1.5，每点 10~12 周期，全程约 2 min），幅值按频段分档；最好再跑一轮不同幅值做线性度检查。
2. **辨识**：逐频点正弦最小二乘 → 复频响 → 剔除粘滑/欠采样点 → 灰箱线性最小二乘（位置通道与速度通道各一套）→ 用摩擦描述函数定 τ_c。公式、判据、脚本清单见 [references/identification_and_design.md](references/identification_and_design.md)。
3. **设计**：闭式解求 (Kp, Ki)，使穿越频率与相位裕度同时达标（内环 PM≈65°、外环 PM≈60°、内/外带宽比≥2.5）；带宽上限由机械纹波决定，用 `|C·S|@纹波频率 < 1` 约束。
4. **落地**：增益换算成固件形式（`Ki_code = Ki_cont·Ts`、`Kd_code = Kd_cont/Ts`）→ 编译 → **校验镜像里确实是新值** → 烧录。固件侧要加的模式/变量、限位表、编译烧录命令见 [references/firmware_hooks.md](references/firmware_hooks.md)。
5. **验证**：用固件的阶跃模式跑实机 → 导出 CSV → 与模型叠图 → 报上升/超调/稳定/峰值力矩，并确认 `saturated_ticks=0`（被限幅削顶过就不能拿模型说事）。

## 会卡住你的四件事（动手前先确认）

- **采样率**：Ozone 普通 Data Sampling 只有 20~30 Hz，100~300 ms 的上升沿只有 3~8 个点，**量不准上升时间**（超调/稳定时间勉强可用）。要准确上升沿只能：固件加 1 kHz 记录并由 MCU 直接算指标、或重复触发几十次叠加。Ozone 的 HSS 在 CMSIS-DAP(DAPLink) 上起不来（Error 81），且需要 RTT 控制块。
- **Ozone 采样列表只认纯全局符号**：`Gimbal.motors[1].ctrl.tor_set` 这类结构体成员/数组下标表达式进不了采样（HSS 直接报错、普通采样也挑食）；在固件里加镜像变量（如 `yaw_torque_log`）。
- **带点的列名**：MATLAB 读表必须 `readtable(..., 'VariableNamingRule','preserve')`，否则列名被改写。
- **数据文件定位**：自动搜 CSV 要**递归搜**且**按表头列名筛选**（扫频 CSV 与阶跃 CSV 不是同一套列），否则会把最新的无关文件当成扫频数据。

## 交付物清单

一次完整整定应留下：辨识脚本+图（Bode / 结构诊断 / 时域校验）、设计族表（目标穿越频率→增益→实测 PM/GM）、固件改动（含镜像校验）、实机 vs 模型叠图、以及一份 Ozone 操作说明（变量顺序与判读）。
