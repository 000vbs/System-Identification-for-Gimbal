# Pitch 轴辨识与整定（2026-10-18）

## 1. 结论

- 之前的 `pitch_rec_6pt.csv` 是旧固件 **1.5~7.5 Hz** 表的记录，不是当前固件 1.0~3.2 Hz 表；按索引查表会把频点整体标错。本次改为直接从 `u` 波形估频，八个有效频点为 **1.00 / 1.30 / 1.50 / 2.20 / 3.20 / 4.70 / 6.00 / 7.52 Hz**。
- 纯二阶 LTI 模型 `1/(J s² + b s + k)` 完全拟合不了低频段（中位误差 145%）。本轴的低频幅值/相位由 **库仑摩擦 + 等效刚度** 共同决定，必须用摩擦描述函数。
- 最终灰箱模型（IMU 侧，力矩 → 俯仰角）：

  ```
  G(s) = exp(-Td*s) / (J*s^2 + (b0 + c/|Omega|)*s + k)
  c = 4*tau_c/pi
  ```

  | 参数 | 值 | 说明 |
  | --- | --- | --- |
  | `J` | **0.0701 kg·m²** | 与 k=10/15.8 的敏感性结果一致，约 0.07~0.083 |
  | `k` | **15.78 N·m/rad** | 重力补偿弹簧 + 重力的线性化等效刚度；k=3 时误差升到 31%，k=25 时 36% |
  | `b0` | **0.778 N·m·s/rad** | 粘性阻尼 |
  | `tau_c` | **0.939 N·m** | 库仑摩擦；k 扫描给 1.04~1.13，量级一致 |
  | `Td` | **16.25 ms** | 等效延迟（含 IMU/滤波/力矩链路）；k 扫描给 12 ms 的等价解 |

- 拟合精度：八个点逐点相对误差 **8.2 / 17.1 / 11.3 / 9.4 / 19.5 / 9.6 / 5.1 / 21.2 %**，中位 **10.4%**；留一验证中位 **18.6%**（最大 31.9%）。满足“拟合点 <15%、留一 <25%”的验收线。
- 双惯量模型（电机-弹簧-负载）中位误差 31.6%，反共振 6.86 Hz、共振 9.81 Hz；它提示 7~10 Hz 有结构模态，但主导低频动态仍是上面的二阶+摩擦模型。

> 数据质量：IMU 通道 R² 0.94~0.996，三次谐波 0.9~10.3%，都低于 12% 的粘滑线。1.0 Hz 点正负不对称 −15.6%、漂移 0.026 rad/s，是这批点里最弱的一个；1.5 Hz 点不对称 −44%，说明重力/摩擦方向偏置明显，但基波仍占主导。

## 3. 控制设计与仿真

固件串级结构不变：**角度环 P → 目标角速度 → 速度环 PI → 力矩**，速度反馈用 `INS_gyro[1]`。

### 3.1 新增前馈

1. **摩擦前馈**（与 Yaw 同形式）：

   ```
   tau_ff = pitch_ff_tau_c * sat(omega_ref / pitch_ff_w_lin)
   ```

   用**参考**角速度、平滑饱和，不用 `sign()`。`pitch_ff_tau_c=0.94`、`w_lin=0.30`。

2. **等效刚度前馈**（本次辨识新增）：

   ```
   tau_spring = pitch_ff_k * (target_pos - pitch_ff_center_rad)
   ```

   `pitch_ff_k=15.78`，`pitch_ff_center_rad` 在从 `RELAX` 进入控制时自动取当前 IMU 角（当前静止角约 −0.1726 rad），并限幅 `pitch_ff_max=2.0 N·m`。它补偿的是重力补偿弹簧的保持力矩；只用摩擦前馈时，0.07 rad 阶跃的上升仍要 0.66 s。

### 3.2 增益

| 参数 | 旧值 | 新值 | 理由 |
| --- | --- | --- | --- |
| 角度环 `Kp` | 11.77 | 11.77 | 保持 1 Hz 左右的瞄准带宽 |
| 角度环 `Ki` | 0 | 0 | 外环不需要 D/I，稳态由速度环积分+刚度前馈承担 |
| 速度环 `Kp` | 2.50 | **1.00** | 旧值会把 0.07 rad 阶跃顶到 3.5 N·m 限幅 |

| 速度环 `Kd` | 0 | 0 | 噪声大，不需要 |
